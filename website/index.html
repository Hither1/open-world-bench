The information you need was seen hours ago

Most embodied benchmarks fit inside a single episode and a single context window. Open-World Bench (OWB) deliberately does not. Its tasks are designed so that the information needed to act correctly was acquired long before it is needed. The agent has to recall it, re-ground it in the current scene, and act on it, across hours of interaction, across sessions, and after the world has changed.

Five memory axes, shared across every world

  • Spatial

    Recall where a place, resource or object was, and get back to it.

  • Episodic

    Recall what happened: who said what, which door was opened, what a failed attempt already ruled out.

  • Procedural

    Reuse a recipe, build or route discovered many steps earlier.

  • Interference & staleness

    Notice when the world has changed and a memory is no longer true.

  • Cross-session

    Resume a paused episode, or carry knowledge across several episodes in the same world seed.

Tasks are scored on success and on targeted memory probes, such as detours and queries that only the right recollection can solve, not on reward alone.

Evaluation

Checkpoint starts

Episodes can begin after K milestones from a verified reference state. That lets you measure the later, memory-heavy segments even when a model cannot get through the early ones.

Information conditions

Native observation-only, perception-oracle, and privileged. They separate "cannot see or locate things" from "cannot work out what to do or remember it".

Working-memory probes

Short probes that ask the agent to hold a few fresh items for tens of seconds, sometimes reversed or transformed, and use them where the source is no longer visible.

Compare models in the leaderboard. Information conditions are reported separately; overall scores will be published only with a defined aggregation protocol. Environments without a task-success criterion remain unscored.

Get started

Python 3.10+. Every world is available through one shared Gymnasium-style interface.

git clone https://github.com/Hither1/open-world-bench
cd open-world-bench
pip install -e ".[gl,video,dev]"
import owb

env = owb.make_env("teyvat", task="cleansing", variant="full", max_steps=40_000)
obs, info = env.reset(seed=7)

To run a model agent with video, action logs, memory notes and token usage:

pip install -e ".[agent,video]"
python -B -m owb.scripts.benchmark --env skylands teyvat wildlands \
  --seed 7 --steps 12 --size 320 240 \
  --policy claude --claude-account-home ~/.claude --model claude-opus-5-5 \
  --video gif --output runs/trial

APIs will change without notice until a tagged release. See the shared framework guide and the embodied agent guide.
