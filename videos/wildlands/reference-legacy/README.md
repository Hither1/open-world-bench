# Earlier Wildlands checkpoint walkthroughs

`task-a.mp4` and `task-b.mp4` preserve the archived Cycles walkthroughs of
The Frostbound Pass (12 milestones, 1:54) and The Valley Before the Storm
(24 milestones, 3:36). They show compact courses as selected replay states held
on screen, **not continuous gameplay**. Both use a privileged reference
controller and predate the organic-world and working-memory-probe updates.

The files are byte-for-byte copies from the preserved archive. Their SHA-256
hashes match the original summary receipts. `task-a.json` and `task-b.json`
retain those summaries and original chapter timestamps, including Blender
4.5.4 Cycles, OptiX GPU, native 960 × 540 scene resolution, and 48 samples.
Posters are unscaled first frames. No simulation or rendering was changed.

The separate `task-a-excerpt-poster.png` is the first frame of the existing
continuous-motion preview, which covers A01–A05 and A09–A10 only.

See [reference scope](../../../docs/wildlands-reference-demos.md) for the
difference between these preserved recordings and current task traces.
