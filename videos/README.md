# Teyvat demo videos

The full walkthroughs here are legacy CPU renders. New recordings default to
Blender Cycles; see this [verified Cycles replay preview](teyvat-cycles-preview.png)
and its [state/render metadata](teyvat-cycles-preview.json).
The shared recorder also passed an end-to-end check on the full Teyvat island:
[full-world Cycles preview](teyvat-full-cycles-preview.png),
[render/check metadata](teyvat-full-cycles-preview.json).

Open the **MP4** files for the most compatible playback of the existing walkthroughs:

- [12 milestones — 42 seconds](teyvat-12-milestones.mp4)
- [24 milestones — 2 minutes 3 seconds](teyvat-24-milestones.mp4)

These copies use H.264 Constrained Baseline, `yuv420p`, and fast-start metadata.
The WebM files are alternate formats. If a preview was already open, close it
and reopen the MP4 to load the converted file.

[Playback checks and file hashes](playback-verification.json) verify complete
decoding and preserved frame counts and durations. These are compact native
simulator reference courses driven by a scripted oracle; see the
[scope, milestone chapters, and action replay evidence](../docs/teyvat-reference-demos.md).
